# pocketMix — C-5 첫 버전 완료 기준

## 영상과 Pocket

- DB에 등록된 영상 목록이 보관함에 표시된다.
- 실제 영상 두 개 이상을 별도 Pocket에서 동시에 재생할 수 있다.
- 한 영상의 재생·일시정지·탐색이 다른 영상의 재생 상태를 바꾸지 않는다.
- 같은 영상을 다시 선택하면 중복 창 대신 기존 Pocket을 보여준다.

## 창과 소리

- Pocket마다 이동·크기 변경·앞으로 가져오기·최소화·닫기가 동작한다.
- 한 Pocket의 음량과 음소거를 바꿔도 다른 Pocket의 설정은 유지된다.
- 전체 일시정지와 창 정렬이 열린 Pocket에 적용된다.

## 저장과 복원

- 영상별 시청 위치는 일시정지, 앱을 벗어날 때, 재생 중 15초마다 저장된다.
- 앱을 다시 열면 시청 위치·음량·음소거와 창 위치·크기가 복원된다.
- 최소화한 Pocket은 최소화 상태로 복원된다.
- 닫은 Pocket은 자동으로 열리지 않지만, 같은 영상을 다시 열면 이전 설정을 사용한다.
- 복원된 영상은 자동 재생되지 않는다.

## 오류와 검증

- DB 목록을 읽지 못하거나 영상 파일을 열지 못했을 때 오류를 확인할 수 있다.
- 한 Pocket의 재생 오류가 다른 Pocket의 사용을 막지 않는다.
- 위 기능을 Android 에뮬레이터에서 실제 영상으로 검증한다.
- 실제 휴대전화에서 확인하기 전까지 기기 테스트는 '미검증'으로 기록한다.
