# pocketMix — 핵심 사용 장면

## 1. 이 앱을 한 문장으로 설명하면

pocketMix는 저장된 영상 두 개 이상을 각각의 Pocket 창에서 동시에 재생하고, 창의 위치·크기와 영상의 소리를 독립적으로 조절할 수 있는 Android 앱이다.

## 2. 가장 중요한 사용 장면

1. 사용자가 DB에 등록된 영상 목록을 확인한다.
2. 영상 두 개 이상을 선택해 각각 별도의 Pocket으로 연다.
3. Pocket을 이동하고 크기를 바꿔, 여러 영상을 함께 보기 좋은 화면을 만든다.
4. 각 영상을 따로 재생·일시정지·탐색하고, 각각의 음량과 음소거 상태를 조절한다.
5. 앱을 다시 열면 이전에 사용한 영상과 Pocket 배치, 영상별 설정을 불러온다.

## 3. 성공했다고 판단할 기준

- 실제 영상 두 개 이상이 화면에서 동시에 재생된다.
- 한 Pocket의 재생·탐색·음량·음소거를 변경해도 다른 Pocket의 설정은 바뀌지 않는다.
- 각 Pocket을 이동하거나 크기를 변경할 수 있다.
- 앱을 다시 열면 영상별 시청 위치, 음량·음소거 상태, Pocket의 위치·크기가 복원된다.
- 복원 직후 영상은 일시정지 상태이며, 사용자가 재생을 선택할 수 있다.
- DB에 등록된 영상을 다시 불러와 이전 시청 상태로 이어 볼 수 있다.

## 4. 첫 버전에서 검증할 범위

첫 버전에서는 pocketMix 앱 안에 저장 영상 두 개 이상을 동시에 열고 조작하는 기능을 만든다. DB에서 영상 목록과 저장된 상태를 가져오고, 변경한 시청 위치와 Pocket 설정을 다시 저장한다.

다른 앱의 화면이나 소리를 pocketMix가 직접 제어하는 기능은 첫 버전의 완료 기준에 넣지 않는다. 다른 앱을 사용하면서 pocketMix 영상을 보는 방식은 핵심 기능이 동작한 뒤 별도로 검증한다.
