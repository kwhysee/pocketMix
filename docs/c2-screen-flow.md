# pocketMix — 화면 흐름

## 앱 시작

- 저장된 작업 공간이 있으면 작업 공간을 연다. 영상은 일시정지 상태로 복원한다.
- 저장된 작업 공간이 없으면 영상 보관함을 연다.
- DB에서 영상을 읽는 동안에는 불러오는 상태를 보여준다.
- 불러오지 못하면 오류와 다시 시도 버튼을 보여준다.

## 영상 보관함 → 작업 공간

1. 보관함에 DB에 등록된 영상 목록을 보여준다.
2. 사용자가 영상의 'Pocket에 열기'를 누른다.
3. 작업 공간으로 이동하고 선택한 영상의 Pocket을 만든다.
4. 작업 공간의 '영상 추가'를 누르면 영상 선택창을 연다.
5. 다른 영상을 선택하면 기존 Pocket을 유지하면서 새 Pocket을 추가한다.

## 작업 공간에서의 조작

- Pocket 제목을 잡으면 창을 이동한다.
- Pocket을 선택하면 앞으로 가져온다.
- 각 Pocket에서 크기 변경, 최소화, 다시 열기, 닫기를 할 수 있다.
- 재생·일시정지·탐색·음량·음소거는 각 Pocket 안에서 조작한다.
- '모두 일시정지'와 '창 정렬'은 작업 공간 전체에 적용한다.

## 예외 흐름

- 보관함에 영상이 없으면 빈 화면과 영상 준비 안내를 보여준다.
- 열린 Pocket이 없으면 보관함으로 갈 수 있는 버튼을 보여준다.
- 영상 하나가 재생되지 않아도 다른 Pocket은 계속 사용할 수 있게 한다.
- 저장된 작업 공간의 영상이 DB에서 삭제되었다면 해당 Pocket에 안내를 보여준다.
