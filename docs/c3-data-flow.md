# pocketMix — C-3 데이터 흐름

## 1. DB에서 영상을 열기까지

1. 앱이 DB에서 영상 목록을 읽어 보관함에 보여준다.
2. 사용자가 영상을 선택하면 영상 ID로 해당 영상의 정보와 이전 시청 상태를 찾는다.
3. 영상 파일을 플레이어에 연결하고 해당 영상의 Pocket을 만든다.
4. 이전 시청 위치·음량·음소거 설정이 있으면 적용한다. 재생은 사용자가 직접 시작한다.

첫 버전에서는 같은 영상을 Pocket 하나에만 연다. 이미 열린 영상을 다시 선택하면 새 Pocket을 만들지 않고 기존 Pocket을 보여준다.

## 2. 따로 관리하는 두 종류의 상태

- 영상별 상태: 영상 ID, 마지막 시청 위치, 음량, 음소거 여부
- Pocket 상태: 연결된 영상 ID, 창 위치·크기, 앞뒤 순서, 열림·최소화·닫힘 상태

영상 ID를 기준으로 두 상태를 연결한다. 한 Pocket에서 재생하거나 음량을 바꿔도 다른 영상과 Pocket의 상태는 바뀌지 않는다.

## 3. 상태를 저장하는 시점

- 시청 위치: 일시정지할 때, 재생 위치를 직접 옮긴 뒤, 앱을 벗어날 때, 재생 중 15초마다 저장한다.
- 음량·음소거: 조작을 마치면 저장한다.
- 창 위치·크기: 이동이나 크기 변경을 마치면 저장한다.
- 최소화·닫기: 해당 버튼을 누르면 바로 상태를 저장한다.

15초는 첫 구현에서 사용할 저장 간격이다. 실제 동작과 DB 요청량을 확인한 뒤 조정할 수 있다.

## 4. 앱을 다시 열 때

1. 저장된 Pocket 상태를 읽는다.
2. '열림' 상태인 Pocket은 작업 공간에 다시 표시한다.
3. '최소화' 상태인 Pocket은 최소화된 목록에 표시한다.
4. '닫힘' 상태인 Pocket은 작업 공간에 표시하지 않는다.
5. 각 영상의 시청 위치와 음량 설정을 복원한다. 영상은 일시정지 상태로 둔다.

열려 있거나 최소화된 Pocket이 하나도 없으면 보관함을 보여준다.

## 5. Pocket을 닫은 뒤 같은 영상을 다시 열 때

Pocket을 닫아도 해당 영상의 시청 위치·음량과 마지막 창 설정은 지우지 않는다.
사용자가 보관함에서 그 영상을 다시 열면 이전 설정을 적용한 Pocket을 만든다.
영상은 저장된 시청 위치에 멈춘 상태로 열린다.

## 6. 오류가 생길 때

DB에서 목록을 읽지 못하면 오류와 다시 시도 버튼을 보여준다.
영상 하나를 불러오지 못하면 해당 Pocket에 오류를 표시하고, 다른 Pocket은 계속 사용할 수 있게 한다.
저장된 영상이 DB에서 없어졌다면 앱이 종료되지 않도록 안내하고, 사용자가 그 Pocket을 정리할 수 있게 한다.
